# L2idle

Protótipo jogável de um MMORPG medieval para navegador, com exploração em mapa 2D, caça ativa, classes, combate opcionalmente automático, paper doll, enchant, mercado, bosses e PvP.

## Demo

Após a ativação do GitHub Pages, o jogo ficará disponível em:

<https://joaovictorsan-ai.github.io/l2idle/>

## Executar localmente

O protótipo está em [`prototypes/valdora-idle`](prototypes/valdora-idle). Você pode abrir o arquivo `index.html` diretamente no navegador ou iniciar um servidor local:

```powershell
cd prototypes\valdora-idle
python -m http.server 8088
```

Depois, acesse <http://localhost:8088>.

Consulte a [documentação do protótipo](prototypes/valdora-idle/README.md) para conhecer os recursos já implementados e o escopo desta versão.
